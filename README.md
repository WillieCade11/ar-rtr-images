# Ag Right to Repair weekly graphics

Public images for the weekly Ag Right to Repair email from Willie Cade, Graceful Solutions LLC.
Served at https://images.graceful.solutions/

Conventions: one PNG per week, no wider than 1200 pixels, under 300 KB, named YYYY-MM-DD-short-title.png using the Sunday of the week it is first sent. Files are never changed or removed after sending; a correction gets a new file name. Add each new file to index.html.
